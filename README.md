## 1. Deskripsi Proyek
`diary-app6` adalah aplikasi catatan harian (*diary*) berbasis React Native menggunakan Expo Router. Aplikasi ini dirancang untuk memenuhi Tugas Praktikum Modul 6 dengan fitur unggulan berupa pencarian teks, filter berdasarkan *mood*, pengelolaan daftar favorit, serta sinkronisasi status *Like* secara global menggunakan React Context.

---

## 2. Cara Menjalankan Proyek (Instructions)
1. **Ekstrak atau buka direktori proyek** (`diary-app6`) di dalam terminal atau Command Prompt VS Code.
2. **Instal dependensi** lalu perintah "npx expo start"
